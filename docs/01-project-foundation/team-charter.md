# ShelfLife — Team Charter

Lana Tran – Requirements/Product Lead

- Maintain project scope and business requirements

- Ensure requirements remain consistent with the checkout transaction

- Identify and document changes to project requirements

Syed Raza – UI/Accessibility Lead

- Design the checkout interface

- Maintain clear form structure and labels

- Ensure required fields and validation messages are understandable

Casey Nguyen – JavaScript/Logic Lead

- Implement checkout business rules

- Ensure invalid transactions are rejected appropriately

- Implement checkout logic and item-state transitions

Ebrahim Vejlani – Git/Integration Lead

- Maintain repository organization

- Coordinate branches and oull requests

- Help ensure all team members can clone, pull, commit, and push

Kim Nguyen – QA/Documentation Lead

- Develop and maintain test cases

- Verify business rules and acceptance criteria

- Identify and document defects before milestones are submitted

Communication:

Use Discord for communication. If a team member cannot make a meeting, be sure to ask another member to recap them. Please try to respond within 24 hours.

Github Workflow:

Pull the latest version of the repository before beginning work. Create a focused branch for significant changes rather than making unrelated changes on ‘main’. Write meaningful commit messages describing the changes made. Please do not overwrite or remove another’s member’s work before communicating.

Accountability: Every team member is responsible for contributing meaningful to the work and needs to understand the code behind it. If a member misses a meeting/commitment, they must first communicate to the team. All team members share responsibility for reviewing every milestone/final project before submission.
